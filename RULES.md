# Правила бота новостей «Свои на юге Афин»

1. Одна новость в день, в 10:00 по Афинам, только в ветку «Новости» (thread 4). Без проверки человеком.
2. Структура: заголовок, 4-5 предложений пересказа (перевод DeepL, без ИИ-генерации), строка «Источник» со ссылкой, хэштеги.
3. Нет ссылки или нет хэштега: пост не выходит (validate в bot.py).
4. Хэштеги только из закрепа: #закон #налоги #аренда #недвижимость #документы #визы #транспорт #быт #цены #срочно; по месту #Греция #Афины #юг_Афин.
5. Источники: уровень A (ведомства и муниципалитеты) важнее уровня B (надёжные издания). Только прямые ленты, не Google News. Только Греция и Афины.
6. Для налогов, законов и виз из изданий уровня B в строке источника пометка «по данным СМИ».
7. Проверка на дубли: (а) по нормализованной ссылке, (б) по заголовку на русском (пересечение слов и чисел) за последние 14 дней и между кандидатами дня; при дубле побеждает источник уровня A.
8. Записи с датой в будущем и старше 72 часов отбрасываются. Интервью, видео и подкасты пропускаются.
9. Правок с пометкой «Обновлено» нет: Telegram сам показывает «изменено».


## Структура поста (с 24.11.2026)
1. 📰 Заголовок жирным (перевод DeepL).
2. Пересказ новости в 2-3 предложениях.
3. **Что это значит для вас:** 1-2 предложения.
4. **Что взять во внимание:** одно предложение, практический совет.
5. Источник со ссылкой (для СМИ пометка «по данным СМИ») и хэштеги.

Пункты 2-4 пишет бесплатная модель Claude (ежедневная задача) (openai/gpt-4.1) строго по тексту статьи: никаких фактов, цифр и советов,
которых нет в статье; нейтральный тон, без политики и оценок, без «!» и длинных тире. Если по статье нельзя честно
сказать, что она значит для жителя Греции, новость пропускается и берётся следующая. Бот проверяет число предложений
в каждом пункте и наличие обоих жирных пунктов, иначе пост не уходит.

## Ветка «Где, что и как в Афинах» (с 24.11.2026)
- Пн достопримечательность, Ср ресторан или кофейня, Пт место отдыха / для семьи с детьми; 12:00 по Афинам; примерно 2 из 3 постов про юг.
- Пост: альбом 2-10 фото (только свободные лицензии: Wikimedia Commons, Unsplash, Pexels) + подпись до 1024 знаков: название, 2-3 предложения, «Совет от своих:», часы и цены, если есть (непроверенные цифры с пометкой источника), ссылка Google Maps, строка «Фото:», хэштеги только из закрепа (один «что» и один «где»).
- Файлы места: places/<slug>/post.json + фото; реестр places/registry.json не даёт повторить место. Запуск: workflow svoi-places (slug, dry_run, delete_message_ids).

## Ветка «Афиша» (тема 31, с 24.11.2026)
- Каждый четверг 12:00 по Афинам, события на ближайшие пт-вс, 3-5 штук, Афины с упором на юг и центр. Без политики, без мероприятий государственных структур (Русский дом и т.п.).
- Выпуск: afisha/<дата четверга>/post.json (dates, events[day,time,name,place,tags], caption в HTML) + bg.jpg. Подпись до 1024 знаков: у каждого события карта и источник, строка «Фон:» с автором и лицензией, без хэштегов.
- Фон подбирается по главной теме недели (праздники/огни - зимний, концерты - вечерний город, выставки - Акрополь/старый город, дети - парк, лето - море). Только свободные лицензии.
- Бот рендерит обложку (afisha_render.py), публикует фото с подписью, закрепляет новый выпуск и открепляет прошлый. Workflow svoi-afisha (issue, dry_run).
